## Instructions
**Note**: Throughout this live hacking lab, please feel free to raise your hand for assitance. A lab technician or presenter would be happy to assist.

Additionally, all `inject.bin` files we use today are available in case you get lost or have any issues. These `inject.bin` files are compiled binary (not human-readable). It is **highly** recommended that you always generate your own; however, as this is a hands-on hacking lab using provided hardware, it is safe to do so this time.
1. Open your Rubber Ducky and place the stickers on it so that when it is closed up, the stickers are on top of the button.
    1. Please raise your hand if you need any assistance opening it up. We have pry tools that will open it for you quickly.
2. Navigate to https://payloadstudio.com/community/
3. Press the button on the Ducky to place it into Storage Mode.
4. Copy the text from the relevant `payload.txt` found in this repository into the PayloadStudio editor.
5. Press the Generate Payload button at the bottom left of the screen.
6. Download the payload (and source if desired).
7. **CUT** and paste the downloaded files into your Ducky.
    1. You *can* copy and paste if you prefer; however, make sure to delete the original file afterwards as it **must** be exactly `inject.bin` in order for the Ducky to use it—`inject (1).bin` will **not** work.
8. Repeat steps 3–7 for each example.

### Friendly reminder: This lab is for hands-on red team training in approved environments only. Make sure you have permission before using these techniques anywhere else.
